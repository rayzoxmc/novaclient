Installation

Prêt en quatre étapes.

1

Installez Fabric

Installez Fabric Loader et Fabric API pour votre version de Minecraft.

2

Téléchargez le mod

Récupérez le .jar correspondant à votre version ci-dessus.

3

Copiez dans « mods »

Placez le fichier dans le dossier .minecraft/mods.

4

Lancez le jeu

Démarrez le profil Fabric et ouvrez le menu du mod en jeu.

FAQ

Questions fréquentes.

Nova Client est-il gratuit ?

Oui, le téléchargement et l’utilisation sont gratuits.

Quelles versions de Minecraft sont supportées ?

Les versions listées dans la section Téléchargement, sous Fabric. D’autres sont ajoutées à chaque mise à jour.

Comment vérifier mon fichier ?

Comparez la somme SHA-256 de votre .jar avec celle affichée sous le bouton de téléchargement.

Le mod ne se lance pas, que faire ?

Vérifiez que Fabric API est installé et que la version du mod correspond à celle de Minecraft.

Prêt quand vous l’êtes.
