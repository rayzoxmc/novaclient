Installation

Prêt en quatre étapes.

Téléchargez

Cliquez sur le bouton : la page Gofile s’ouvre, puis téléchargez NovaLauncher-1.0.0-win.exe.

Installez

Lancez le fichier. Si SmartScreen s’affiche : « Informations complémentaires », puis « Exécuter quand même ».

Connectez-vous

Onglet Account, puis « Sign in with Microsoft ».

Créez et jouez

Créez une instance, ajoutez des mods depuis Discover et cliquez sur Play.

FAQ

Questions fréquentes.

Nova Launcher est-il gratuit ?

Oui, le téléchargement et l’utilisation sont gratuits.

Pourquoi Windows affiche-t-il un avertissement ?

L’application n’est pas encore signée numériquement, ce qui déclenche SmartScreen sur les nouveaux fichiers. Vérifiez la somme SHA-256 avant de lancer l’installateur si vous voulez être sûr du fichier.

Comment vérifier mon fichier ?

Dans PowerShell : Get-FileHash .\NovaLauncher-1.0.0-win.exe, puis comparez avec la somme affichée sur cette page.

Mon mot de passe est-il stocké ?

Non. La connexion passe par la fenêtre officielle de Microsoft. Seul un jeton de session est conservé, chiffré avec le trousseau de Windows.

Faut-il installer Java ?

Oui, Java doit être installé sur votre PC : Java 21 pour Minecraft 1.20.5 et plus, Java 17 pour les versions précédentes.

Je n’ai pas de compte Microsoft, puis-je jouer ?

Un mode hors-ligne est disponible avec un pseudo de votre choix. Il fonctionne en solo et sur les serveurs qui l’autorisent.

Prêt quand vous l’êtes.

Gratuit, installé en moins d’une minute.
